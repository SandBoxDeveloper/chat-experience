# Chat Experience (PWA)

A simplified, mobile-friendly Progressive Web App (PWA) chat interface built with React, TypeScript, Vite, and Tailwind CSS.

## ✨ Features

- 🔤 Text chat input
- 📸 Image selection from gallery
- 🎥 Live camera access and photo capture
- 🎙️ Microphone recording (3 seconds, audio playback)
- 💅 Responsive chat-style UI like ChatGPT

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) to use the app.

### Build for production

```bash
npm run build
```
